Settings Theme — carousel mocks

The shipped theme picker is a vertical stack of five full-width cards — readable, but long and repetitive. Each mock keeps the real Settings layout (dial, language, feedback) and replaces only the theme section with a horizontal carousel pattern.

Mock 1

Peek carousel

Center card full width; neighbors peek at the edges. Swipe to browse — compact height, strong “there’s more” affordance.

 Mock 2

Snap cards + dots

One theme per viewport with scroll-snap. Dot pagination and name/description below — familiar iOS picker rhythm.

 Mock 3

Cover flow

3D perspective stack — center theme prominent, flanking cards recede. Feels tactile and premium; best for visual themes.

 Mock 4

Hero + strip

Large live preview of the selected palette on top; swipeable thumbnail strip below. Wallpaper-picker pattern — see before you commit.

 Mock 5

Mini phone frames

Each theme rendered as a tiny in-app screenshot inside a phone silhouette. Shows the whole experience, not just swatches.

 Mock 6

Cover flow + phones

Hybrid of Mock 3 and 5 — bezel-free 3D carousel; each theme previews a different tab with abstract UI shapes (no dua text).

Current (app): vertical list of five theme cards inside one parchment Card — swatches, name, and description stacked; selected state is a thicker border.
